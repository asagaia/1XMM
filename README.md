## 1xMM Project [https://www.one-xmm.com]
1xMM aims at offering new generation pools which involve **Perpetual Constant Maturity Options** (PCMOs).<br/>
Thanks to the **1xMM Pools**, users have the opportunity to take positions on synthetic **Perpetually Rolled Futures**, which are a combination of 1 PCMO Call and 1PCMO Put.<br/>
1xMM Project is the 1st step of Asagaia initiative [https://www.asagaia.com] which aims at founding the _Metabank of Tomorrow_.

## The 1XMM token
As part of the 1xMM Pools ecosystem, the 1XMM token has been designed as an exchange token offering the following benefits:
1. Rebates when using 1xMM Pools
2. Auto-exchangeability, to faciliate exchange and to support the price of the token
3. Burnability, to create a deflationary token
4. Cross-chain interoperability, since 1XMM is a CCT token using ChainLink protocol

# Initial distribution of 1XMM Tokens
Total Maximum Supply: a hard cap of **650,000,000 1XMM** tokens has been fixed<br/>
The distribution of these tokens will be as follows:
+ 10,000,000 tokens for private seed
+ 20,000,000 tokens in exchange of bonuses purchased through our Telegram mini-app
+ Up to 15,000,000 tokens for Telegram mini-app ranking
+ 15,000,000 tokens for pre-sale round
+ 72,500,000 tokens for sale round
+ 15,000,000 tokens for marketing purpose / ecosystem bootstrapping (incl. airdrop for telegram mini-app)
+ 65,000,000 tokens for token liquidity management purpose (i.e. DEX | AMMs | Buy/Sell)
+ 162,500,000 tokens for financing purpose (i.e. in favor of Asagaia initiative, to finance upcoming projects)
+ 260,000,000 tokens dedicated to the 1XMM pool, to deliver yields to 1XMM stakers
+ 15,000,000 tokens for the team

# Lock period
To protect participants who will have purchased some 1XMM tokens (either during seed, pre-sale or sale period), a `lock` functionality has been implemented to prevent significant price fluctuations caused by early participants selling tokens acquired during the initial growth phase. The lock-up period will remain until October 2025, following the token sale, once sufficient price stability and liquidity have been established.
